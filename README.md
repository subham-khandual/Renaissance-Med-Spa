# Renaissance med spa ai Assistant

A responsive EduSkill landing page and chat-interface preview built with React, Vite, JavaScript, and Tailwind CSS. The design follows the project design guide's warm neutral palette and restrained aesthetic.

**Developer:** [@subham-khandual](https://github.com/subham-khandual)

## Start the app

```sh
npm install
npm run dev
```

## Project structure

Application code is organized under `src/app`, `src/components`, `src/content`, `src/pages`, `src/hooks`, `src/lib`, and `src/styles`. This project uses `.js` and `.jsx` files, not TypeScript.

Place the approved Sayraa character artwork at `public/images/sayraa-guide.png`. Until then, the landing page shows a CSS illustration placeholder.

The chat widget is a frontend preview only. It does not call an AI service or transmit messages. Connect it to a secure server-side endpoint to enable real responses.
